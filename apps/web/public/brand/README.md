# Brand assets

`msf-logo-positive-ca.svg` is the positive logo (red symbol, black name) in Catalan, from MSF's branding guidelines at branding-guidelines.msf.es. It is shown in the footer and set in `src/brand.ts`.

Rules from the guidelines: use the complete logo, never the symbol alone, with clear space of a quarter of the symbol's height around it. Positive logo on light backgrounds, negative (red symbol, white name) on dark ones.
