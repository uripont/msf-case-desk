# Context

Quoroom is for case managers and committee members in MSF's ethics and behaviour functions, starting with the Ethics & Behaviour Unit. It is an **internal** tool: it starts from a case that has already arrived and never takes reports from reporters.

## The existing platform

MSF's public Integrity Line page (msf.ch/integrity-line) links to a hosted platform run by EQS Group, operated per operational centre. Reporters make a complaint or ask a question there, with a personal secure account for follow-up, and a committee decides the action. This was read from the public pages only; nothing was submitted and no internal system was accessed.

## Boundaries

| Quoroom does | Quoroom does not |
| --- | --- |
| Draft, redact, review and approve the reports about a case | Collect complaints or questions from reporters |
| Reference a case by its identifier (the case file's reference) | Copy case content out of the Integrity Line |
| Keep every draft, revision, review and decision with an audit log | Create reporter accounts or secure reporter messaging |
| Record the committee's approval of a report | Replace the committee's authority over outcomes |
